# Clothing Store API

A simple REST API for managing clothing items in a clothing store.

## Technologies

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy

## API Operations

The API can:

- Get all clothing items
- Get one clothing item by ID
- Add a new clothing item
- Update a clothing item
- Delete a clothing item

## Database

The project uses PostgreSQL to store the clothing records.
